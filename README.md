# 🐍 Python Beginner Projects Collection

Welcome to my Python projects repository! This collection contains five mini-projects built with Python to demonstrate core programming concepts, logic building, and working with external APIs.

---

## 🚀 Projects Included

### 1. 🎮 Number Guessing Game (`main.py`)
An interactive game where the player tries to guess a secret random number between 1 and 10 with feedback on each attempt.
* **Features:**
  * Random number generation.
  * Try-except error handling for invalid inputs.
  * Attempt counter to track performance.

### 2. 🧮 Python Calculator (`calculator.py`)
A simple interactive command-line calculator that performs basic arithmetic operations.
* **Features:**
  * Addition (`+`), Subtraction (`-`), Multiplication (`*`), and Division (`/`).
  * Input validation and error handling (prevents division by zero).

### 3. 🔐 Password Generator (`password_generator.py`)
A secure tool that generates random, customizable passwords to help improve online security.
* **Features:**
  * Custom password length support.
  * Options to include numbers and special characters.
  * Shuffled outputs for high randomness.

### 4. 💰 Expense Tracker (`expense_tracker.py`)
A personal finance tracker script that helps users log and manage their daily expenses.
* **Features:**
  * Add expenses with amount, category, and notes.
  * View recorded expenses.
  * Calculate and display total spending.

### 5. 🌦️ Weather App (`weather_app.py`)
A real-time weather information application fetched from the OpenWeatherMap API.
* **Features:**
  * Fetches temperature, weather conditions, humidity, and wind speed.
  * Handles invalid city inputs and API errors smoothly.
